# Dapur Nusa

Website UMKM Dapur Nusa merupakan proyek praktikum Cloud Computing untuk menyediakan informasi usaha kuliner melalui website yang di-deploy pada VPS IDCloudHost.

## Teknologi yang Digunakan
- Ubuntu Server
- Nginx sebagai web server
- HTML dan CSS

## Deployment
Website dijalankan pada VPS IDCloudHost dengan sistem operasi Ubuntu dan dapat diakses melalui IP publik server.

## Pemeliharaan
- Konfigurasi firewall untuk keamanan server.
- Backup berkas website dan konfigurasi Nginx.
- Pemeriksaan layanan website untuk memastikan website berjalan dengan baik.

## Tujuan Proyek
Menerapkan konsep cloud computing melalui proses konfigurasi server, deployment website, keamanan, backup, dan monitoring.
